How do I get a Client ID and Spreadsheet ID?
  1. In Google Cloud Console, create (or pick) a project, then enable the Google Sheets API under "APIs & Services".
  2. Under "APIs & Services → Credentials", create an OAuth client ID of type Web application.
  3. Add this page's exact URL (the address bar right now, without anything after it) under Authorized JavaScript origins. This page must be served from a real http:// or https:// address — opening the file directly (file://) will not work.
  4. Copy the generated Client ID (ends in .apps.googleusercontent.com) into the field below.
  5. Open your Google Sheet, copy the long ID from its URL — the part between /d/ and /edit — into the Spreadsheet ID field.
  6. Make sure the Google account you sign in with has at least edit access to that sheet.
